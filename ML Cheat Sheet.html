1. Data Splitting & Sampling [scikit-learn]

  • Train/validation/test split to avoid data leakage. Use stratified split for imbalanced classes.
  • Use GroupKFold or TimeSeriesSplit for grouped or sequential data (e.g., user or time-based splits).
  • Consider stratified group k-fold for fairer splits in user-based data (see scikit-learn 1.5).
from sklearn.model_selection import train_test_split, StratifiedGroupKFold
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=42)
# For grouped data (e.g. medical studies, users):
sgkf = StratifiedGroupKFold(n_splits=5)
for train_idx, test_idx in sgkf.split(X, y, groups=group_labels):
    X_train, X_test = X[train_idx], X[test_idx]
Desirable: 70-80% Train, 10-20% Validation, 10-20% Test.
Interpretation: Ensures generalizability and prevents overfitting/leakage.
Example: For 10,000 samples, use 7,000 train, 1,500 val, 1,500 test.

2. Cross-Validation & Resampling [scikit-learn]

  • Use StratifiedKFold for classification, GroupKFold for grouped data, TimeSeriesSplit for temporal data.
  • For large datasets, use ShuffleSplit or RepeatedKFold for efficiency.
from sklearn.model_selection import cross_val_score, StratifiedKFold, TimeSeriesSplit
cv = StratifiedKFold(n_splits=5)
scores = cross_val_score(model, X, y, cv=cv)
Desirable: 5 or 10 folds. Use cv=3 for fast prototyping.
Interpretation: Reliable performance estimate; less variance than single split.
Example: CV scores: [0.87, 0.86, 0.89, 0.88, 0.87] → mean = 0.874

3. Model Evaluation Metrics [scikit-learn]

  • Classification: Use F1, ROC-AUC, PR-AUC (preferred for imbalanced data), accuracy (if balanced), log loss for probabilistic models.
  • Regression: Use R², RMSE, MAE.
  • Clustering: Use Silhouette score, ARI, NMI.
  • 2025: Consider calibration metrics for probabilistic models (sklearn.calibration.CalibrationDisplay)!
from sklearn.metrics import (accuracy_score, f1_score, roc_auc_score, confusion_matrix, mean_squared_error, r2_score)
y_pred = model.predict(X_test)
print("F1:", f1_score(y_test, y_pred))
print("ROC-AUC:", roc_auc_score(y_test, model.predict_proba(X_test)[:,1]))
print("Confusion Matrix:\n", confusion_matrix(y_test, y_pred))
print("R²:", r2_score(y_test, model.predict(X_test)))
Desirable: F1/ROC-AUC > 0.8 (good), R² close to 1.
Interpretation: Higher is better for F1, ROC-AUC, R². Lower is better for RMSE/MAE.
Example: F1 = 0.86, ROC-AUC = 0.91 (good); R² = 0.92 (explains 92% of variance)

  • Use the right tuning strategy for each model (see below).
  • 2025: For deep learning, try KerasTuner or Optuna with Ray Tune for distributed search.

Neural Networks (MLP, Deep Learning)
from keras_tuner import RandomSearch
def build_model(hp):
    from keras.models import Sequential
    from keras.layers import Dense
    model = Sequential()
    model.add(Dense(units=hp.Int('units', 32, 128, step=32), activation=hp.Choice('activation', ['relu','tanh'])))
    model.add(Dense(1, activation='sigmoid'))
    model.compile(optimizer=hp.Choice('optimizer',['adam','rmsprop']), loss='binary_crossentropy', metrics=['accuracy'])
    return model

tuner = RandomSearch(build_model, objective='val_accuracy', max_trials=5, executions_per_trial=2, directory='my_dir')
tuner.search(X_train, y_train, epochs=10, validation_data=(X_val, y_val))
Desirable: Use KerasTuner, Optuna, or Ray Tune for deep learning.
Example: Best params: {'units': 64, 'activation': 'relu', 'optimizer': 'adam'}
General tips:
- Always use cross-validation when tuning hyperparameters.
- For very large datasets, consider subsampling or early stopping.
- For imbalanced data, tune class_weight or scale_pos_weight as well!

5. Learning Curves & Validation Curves [sklearn]

  • Learning curve: Plot score vs train size. Validation curve: Score vs. hyperparameter.
  • 2025: Use scikit-learn's plot_learning_curve for quick visualization (v1.4+).
from sklearn.model_selection import learning_curve
import matplotlib.pyplot as plt
train_sizes, train_scores, val_scores = learning_curve(model, X, y, cv=5)
plt.plot(train_sizes, train_scores.mean(axis=1), label="Train")
plt.plot(train_sizes, val_scores.mean(axis=1), label="Validation")
plt.legend(); plt.show()
Desirable: Training and validation scores converge with more data.
Interpretation: Large gap = overfitting, both low = underfitting.
Example: If train=0.99, val=0.78 → overfitting; both ≈0.78 → good fit.

7. Residual/Error Analysis [sklearn example]

  • Regression: Plot residuals (should be random), Q-Q plot (should be straight line).
  • Classification: Analyze misclassified samples.
import matplotlib.pyplot as plt
residuals = y_test - y_pred
plt.scatter(y_pred, residuals)
plt.axhline(0, color="red")
plt.xlabel("Predicted"); plt.ylabel("Residuals"); plt.show()
Desirable: Residuals scattered randomly around zero.
Interpretation: Patterns indicate model misses nonlinearity or heteroscedasticity.
Example: If all residuals above 0 for high predictions → model underpredicts at high values.

8. Durbin-Watson Statistic (Autocorrelation in Residuals) [statsmodels] [Wikipedia]

  • Check for autocorrelation in regression residuals (important in time series).
from statsmodels.stats.stattools import durbin_watson
dw = durbin_watson(residuals)
print("Durbin-Watson:", dw)
Desirable Range: 1.5 – 2.5 (no autocorrelation)
Interpretation: DW ≈ 2 → No autocorr. DW < 2 → Positive autocorr. DW > 2 → Negative autocorr.
Example: DW = 0.9 (strong positive autocorrelation, likely a time series issue)
DW = 2.1 (no autocorrelation, good)

9. Overfitting & Underfitting Checks [sklearn example]

  • Compare train/test scores (large gap = overfitting, both low = underfitting)
print("Train Score:", model.score(X_train, y_train))
print("Test Score:", model.score(X_test, y_test))
Desirable: Train and test scores are close and both high (≥0.8 for many tasks).
Interpretation: Large gap = overfitting, both low = underfitting.
Example: Train = 0.95, Test = 0.70 (overfit); Train = 0.72, Test = 0.71 (underfit).

10. Robustness & Stress Testing [ART]

  • Add noise, test on adversarial samples, shuffle columns/labels (sanity check).
  • 2025: Use Adversarial Robustness Toolbox (ART) for deep learning robustness.
import numpy as np
X_test_noisy = X_test + np.random.normal(0, 0.1, X_test.shape)
print("Accuracy on noisy data:", model.score(X_test_noisy, y_test))
Desirable: Model accuracy/performance should not drop drastically with small noise.
Interpretation: Large drop = model too sensitive, may be brittle.
Example: Accuracy drops from 0.86 (clean) to 0.83 (noisy) → robust. Drops to 0.60 → fragile!

11. Data Leakage & Bias Checks [Interpretable ML Book]

  • Check that test data is never used in training/feature engineering.
  • Check for target leakage, data snooping, or look-ahead bias.
  • 2025: Use DataFold or Embedded ML Metadata for pipeline tracking.
# Always split data BEFORE feature engineering!
# Check correlations between early features and target
Desirable: No leakage! Only train data for feature engineering.
Interpretation: Leakage inflates test scores, gives false confidence.
Example: Mistakenly using test data to impute missing values introduces leakage.

13. Fairness & Ethics Checks [Fairlearn] [AIF360]

  • Test for disparate impact, demographic parity, equal opportunity.
  • Check model bias across protected groups.
  • 2025: Use Fairlearn and AIF360 for auditing fairness.
# pip install fairlearn
from fairlearn.metrics import demographic_parity_difference
demographic_parity_difference(y_test, y_pred, sensitive_features=group_labels)
Desirable: Difference close to 0 (no group is unfairly advantaged or disadvantaged).
Interpretation: Large difference indicates potential bias.
Example: Demographic parity difference = 0.03 (good). If 0.40 → strong bias!
