ML Algorithm Testing & Validation Cheat Sheet

All types of tests to perform on ML models — with Python code examples, desirable ranges, interpretations, and model-specific hyperparameter tuning

1. Data Splitting & Sampling

  • Train/test/validation split to avoid data leakage.
  • Stratified split for imbalanced classes.
  • Shuffle your data!
from sklearn.model_selection import train_test_split
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=42)
Desirable: 70-80% Train, 20-30% Test.
Interpretation: Ensures fair, unbiased model evaluation.
Example: If you have 1000 samples, 800 for training, 200 for testing.

2. Cross-Validation & Resampling

  • K-Fold, Stratified K-Fold, Leave-One-Out, Repeated CV.
  • Time-Series Split for temporal data.
from sklearn.model_selection import cross_val_score, StratifiedKFold, TimeSeriesSplit
cv = StratifiedKFold(n_splits=5)
scores = cross_val_score(model, X, y, cv=cv)
Desirable: 5 or 10 folds for K-Fold.
Interpretation: More robust estimate of model performance.
Example: You get cross-validation scores: [0.87, 0.86, 0.89, 0.88, 0.87] → mean = 0.874

3. Model Evaluation Metrics

  • Classification: Accuracy, Precision, Recall, F1, ROC-AUC, PR-AUC, Confusion Matrix, Log Loss
  • Regression: MSE, RMSE, MAE, R², Adjusted R²
  • Clustering: Silhouette, Davies-Bouldin, ARI, NMI
# Classification
from sklearn.metrics import (accuracy_score, precision_score, recall_score, f1_score, roc_auc_score, confusion_matrix)
y_pred = model.predict(X_test)
print("Accuracy:", accuracy_score(y_test, y_pred))
print("Precision:", precision_score(y_test, y_pred))
print("Recall:", recall_score(y_test, y_pred))
print("F1:", f1_score(y_test, y_pred))
print("ROC-AUC:", roc_auc_score(y_test, model.predict_proba(X_test)[:,1]))
print("Confusion Matrix:\n", confusion_matrix(y_test, y_pred))
# Regression
from sklearn.metrics import mean_squared_error, mean_absolute_error, r2_score
print("RMSE:", mean_squared_error(y_test, y_pred, squared=False))
print("MAE:", mean_absolute_error(y_test, y_pred))
print("R²:", r2_score(y_test, y_pred))
Desirable (Classification): F1, ROC-AUC > 0.8 (good), Accuracy > 0.8 (if balanced)
Desirable (Regression): R² close to 1, RMSE/MAE small relative to target range
Interpretation: Higher is better for F1, ROC-AUC, R². Lower is better for RMSE/MAE.
Example: F1 = 0.86, ROC-AUC = 0.91 (good); R² = 0.92 (explains 92% of variance)

4. Hyperparameter Tuning (Model-specific Strategies)

  • Use the best optimization approach for each model to maximize performance.
Random Forest / Decision Tree
from sklearn.model_selection import RandomizedSearchCV
param_grid = {
    'max_depth': [3, 5, 10, None],
    'min_samples_split': [2, 5, 10],
    'n_estimators': [50, 100, 200]
}
search = RandomizedSearchCV(RandomForestClassifier(), param_grid, n_iter=10, cv=3)
search.fit(X_train, y_train)
print("Best params:", search.best_params_)
Desirable: Use RandomizedSearchCV for efficiency, especially with many parameters.
Example: Best params: {'max_depth': 10, 'min_samples_split': 2, 'n_estimators': 100}

Neural Networks (MLP, Deep Learning)
from keras.wrappers.scikit_learn import KerasClassifier
from sklearn.model_selection import RandomizedSearchCV

def build_model(optimizer='adam', activation='relu'):
    from keras.models import Sequential
    from keras.layers import Dense
    model = Sequential()
    model.add(Dense(64, input_dim=X_train.shape[1], activation=activation))
    model.add(Dense(1, activation='sigmoid'))
    model.compile(loss='binary_crossentropy', optimizer=optimizer, metrics=['accuracy'])
    return model

param_dist = {
    'optimizer': ['adam', 'rmsprop'],
    'activation': ['relu', 'tanh'],
    'epochs': [10, 20],
    'batch_size': [16, 32]
}
search = RandomizedSearchCV(KerasClassifier(build_fn=build_model, verbose=0), param_distributions=param_dist, n_iter=5, cv=3)
search.fit(X_train, y_train)
print("Best params:", search.best_params_)
Desirable: Use RandomizedSearchCV for neural nets to speed up search; advanced users can use Optuna, KerasTuner, or Ray Tune.
Example: Best params: {'optimizer': 'adam', 'activation': 'relu', 'epochs': 20, 'batch_size': 16}
General tips:
- Always use cross-validation when tuning hyperparameters.
- For very large datasets, consider subsampling or early stopping.
- For highly imbalanced data, tune class_weight or scale_pos_weight as well!

5. Learning Curves & Validation Curves

  • Learning curve: Plots score vs train size. Validation curve: Score vs. hyperparameter.
from sklearn.model_selection import learning_curve, validation_curve
import matplotlib.pyplot as plt
train_sizes, train_scores, val_scores = learning_curve(model, X, y, cv=5)
plt.plot(train_sizes, train_scores.mean(axis=1), label="Train")
plt.plot(train_sizes, val_scores.mean(axis=1), label="Validation")
plt.legend(); plt.show()
Desirable: Training and validation scores converge with more data.
Interpretation: Large gap = overfitting, both low = underfitting.
Example: If train=0.99, val=0.78 → overfitting; both ≈0.78 → good fit.

6. Feature Importance & Model Explanation

  • Tree-based: feature_importances_
  • Linear: coef_
  • Permutation importance, SHAP, LIME, Partial Dependence Plots
# Tree-based
importances = model.feature_importances_

coefs = model.coef_

import shap

shap.summary_plot(shap_values, X_test)
Desirable: Top features align with domain intuition.
Interpretation: Unexpected important features may indicate leakage or discovery!
Example: Feature 'age' has highest importance for predicting insurance charges.

7. Residual/Error Analysis

  • Regression: Plot residuals (should be random), Q-Q plot (should be straight line).
  • Classification: Analyze misclassified samples.
import matplotlib.pyplot as plt
residuals = y_test - y_pred
plt.scatter(y_pred, residuals)
plt.axhline(0, color="red")
plt.xlabel("Predicted"); plt.ylabel("Residuals"); plt.show()
Desirable: Residuals scattered randomly around zero.
Interpretation: Patterns indicate model misses nonlinearity or heteroscedasticity.
Example: If all residuals above 0 for high predictions → model underpredicts at high values.

8. Durbin-Watson Statistic (Autocorrelation in Residuals)

  • Check for autocorrelation in regression residuals (important in time series).
from statsmodels.stats.stattools import durbin_watson
dw = durbin_watson(residuals)
print("Durbin-Watson:", dw)
Desirable Range: 1.5 – 2.5 (no autocorrelation)
Interpretation: DW ≈ 2 → No autocorr. DW < 2 → Positive autocorr. DW > 2 → Negative autocorr.
Example: DW = 0.9 (strong positive autocorrelation, likely a time series issue)
DW = 2.1 (no autocorrelation, good)

9. Overfitting & Underfitting Checks

  • Compare train/test scores (large gap = overfitting, both low = underfitting)
print("Train Score:", model.score(X_train, y_train))
print("Test Score:", model.score(X_test, y_test))
Desirable: Train and test scores are close and both high (≥0.8 for many tasks).
Interpretation: Large gap = overfitting, both low = underfitting.
Example: Train = 0.95, Test = 0.70 (overfit); Train = 0.72, Test = 0.71 (underfit).

10. Robustness & Stress Testing

  • Add noise, test on adversarial samples, shuffle columns/labels (sanity check).
import numpy as np
X_test_noisy = X_test + np.random.normal(0, 0.1, X_test.shape)
print("Accuracy on noisy data:", model.score(X_test_noisy, y_test))
Desirable: Model accuracy/performance should not drop drastically with small noise.
Interpretation: Large drop = model too sensitive, may be brittle.
Example: Accuracy drops from 0.86 (clean) to 0.83 (noisy) → robust. Drops to 0.60 → fragile!

11. Data Leakage & Bias Checks

  • Check that test data is never used in training/feature engineering.
  • Check for target leakage, data snooping, or look-ahead bias.
# Always split data BEFORE feature engineering!
# Check correlations between early features and target
Desirable: No leakage! Only train data for feature engineering.
Interpretation: Leakage inflates test scores, gives false confidence.
Example: Mistakenly using test data to impute missing values introduces leakage.

12. Model Stability & Reproducibility

  • Set random seeds for reproducibility.
  • Test for consistent results across runs.
import numpy as np
np.random.seed(42)
import random
random.seed(42)
# For sklearn:
# model = Model(random_state=42)
Desirable: Results do not change much between runs.
Interpretation: Randomness can mask true model skill if not fixed.
Example: With random_state=42, model accuracy is always 0.86.
